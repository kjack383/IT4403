MILESTONE 1 - OPEN LIBRARY JSON DATA DISPLAY

FILES INCLUDED
--------------
index.html
openlibrary-book.html
openlibrary-search.html
book.js
search.js
style.css

JSON FILES NEEDED
-----------------
Place the instructor-provided files in this same folder:
1. openlibrary-book.json
2. openlibrary-search.json

IMPORTANT
---------
Do not rename the JSON files unless you also change the filenames in
book.js and search.js.

The single-book page reads openlibrary-book.json.
The search-results page reads openlibrary-search.json and uses a loop
to process the docs array.

UPLOAD TO YOUR PUBLIC PROJECT WEBSITE
-------------------------------------
Upload all HTML/CSS/JS files plus both instructor-provided JSON files.
Make sure all files are in the correct relative locations.

The pages use jQuery from the official jQuery CDN. No additional
JavaScript libraries or frameworks are used.

TESTING
-------
Because browsers can block local JSON requests when opening HTML files
directly from your computer, test the finished project through your
public web server/GitHub Pages site.
