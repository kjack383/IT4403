# IT 4403 Student Website

This is a starter public website for IT 4403 – Advanced Web and Mobile Applications.

## Pages
- `index.html` — Home
- `exercises.html` — Exercises
- `labs.html` — Labs
- `projects.html` — Projects
- `style.css` — Site styling

## Hosting
The course Lab 1 recommends a public hosting service and notes that the hosting environment should support file transfer and at least one server-side framework. Microsoft Azure for Students is listed as the recommended option. GitHub Pages is also listed as a free option for static HTML/CSS/JavaScript, but the lab notes that it does not directly support PHP or Node.js.
