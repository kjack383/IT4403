# Milestone 3: Open Library Single Page Application

## Project Overview
This project is a Single Page Application (SPA) that allows users to search for books, view selected book details, navigate search results, and explore a predefined book collection using the Open Library API.

## Features
- Search for books by title or keyword.
- Display up to 50 search results.
- Navigate results with pagination (10 books per page).
- Select a book to view its details, including its Work ID, author, description, subjects, and cover when available.
- Browse a predefined Science Fiction book collection.
- Handle missing information, empty searches, loading states, and API errors.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery and jQuery AJAX
- Open Library Search, Works, Subjects, and Covers APIs

## Project Files
- `index.html` — Main single-page application interface.
- `style.css` — Application styling and responsive layout.
- `script.js` — Search, pagination, API requests, collection, and book details.

## Running the Application
Open `index.html` through a local web server or the deployed application URL. An internet connection is required to retrieve Open Library data.
